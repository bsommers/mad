# mad — Design

This document turns the original brief into decisions an implementer can build from. Where the brief was
ambiguous, stale or wrong about the installed tools, the correction is marked **[fix]**.

## 1. Goal

Send each local development task to the subscription CLI and model that fit it, without API keys. Keep a shared,
grep-able record of what every agent did, so that work can move between `claude` and `agy` mid-task and lose nothing.

**Core value:** a handoff never loses state. Whichever CLI picks up a task gets the unresolved problem and the next
steps in one file, and the global log shows how the task got there.

## 3. State store (OKF Markdown)

The brief chose Markdown over SQLite/Redis, and that decision stands.

**OKF file shape.** Every file in `.active_context/`, and the log header, starts with this frontmatter:

```yaml
---
title: MQTT topology          # human title
keywords: [mqtt, broker, uns] # lower-case match terms for context_fetcher
updated: 2026-10-23           # ISO date of the last meaningful edit
---
```

**`.global_dev_log.md`** has the frontmatter header, then entries appended in this exact format:

```markdown
## 2026-10-23T14:02:11Z · transition · claude
- model: sonnet
- task: debug the mqtt reconnect
- reasons: kw:debug
```

The heading is `## <UTC ISO-8601 seconds, Z> · <kind> · <agent>`. `kind` is one of `task`, `transition`,
`decision`, `handoff`, `note`, and `agent` is one of `claude`, `agy`, `human`, `mad`. The body is `- key: value` lines
with values on a single line (newlines in values are replaced with spaces). Entries are separated by one blank line.
The file is opened in append mode only.

**`.active_context/`** holds one topic per file, named `snake_case.md`, plus `INDEX.md`, generated by
`context_fetcher --reindex` in Phase 2 and listing title, keywords and path for each file.

## 4. Routing

### 4.1 Agent choice

Inputs: the prompt text, the list of files named for the task, and an optional `--agent`/`--model` override.
Keyword phrases match case-insensitively on word boundaries. Lists live in `config/routing.json`:

- `claude_keywords`: `debug`, `write test`, `write tests`, `fix error`, `fix the error`, `failing test`, `red-green`, `tdd`, `stack trace`
- `agy_keywords`: `design`, `architect`, `architecture`, `refactor all`, `ontology`, `bfo`, `cco`, `unified namespace`, `uns`, `documentation set`
- `agy_file_threshold`: 5. More than 5 files counts as one agy signal.

```
claude_score = number of distinct claude_keywords matched
agy_score    = number of distinct agy_keywords matched + (1 if len(files) > agy_file_threshold)
agent        = override  if given
             = "agy"     if agy_score > claude_score
             = "claude"  otherwise   (ties and no signal go to claude: the cheaper, faster loop)
```

### 4.2 Model choice

| Agent | Rule (first match wins) | Model |
|---|---|---|
| claude | `--model` override | as given |
| claude | any `opus_keywords` (`deep bug`, `race condition`, `deadlock`, `heisenbug`, `memory corruption`, `--deep`) | `opus` |
| claude | any `haiku_keywords` (`docstring`, `readme`, `changelog`, `regex`, `lint`, `format`, `typo`), **and** claude_score == 0 | `haiku` |
| claude | otherwise | `sonnet` |
| agy | `--model` override | as given |
| agy | agy_score == 0 (agy was picked only by override) | `gemini-3.8-flash-medium` |
| agy | otherwise | `gemini-4-argon-high` |

**Decision** (the output of `mad route`, as JSON):
`{"agent": "claude", "model": "sonnet", "reasons": ["kw:debug"], "scores": {"claude": 1, "agy": 0}}`.
Reasons are `kw:<phrase>`, `files:<n>>5`, `override:agent`, `override:model` and `default`, in the order they were found.

### 4.3 Model switching inside a session

A running CLI can't be switched by the router. Inside a session, the skills choose models for **subagents**:
Claude's Agent tool `model` takes `haiku`/`sonnet`/`opus`, and agy's `--model` applies per `agy -p` call.
Phase 2 skills state this policy, which is the same table as 4.2.

## 5. Router CLI (`bin/mad`)

| Command | Behavior |
|---|---|
| `mad init` | Creates `.active_context/` (with an INDEX.md stub) and `.global_dev_log.md` (with a header) if missing. Never overwrites. Prints what it created. |
| `mad route PROMPT [FILE...]` | Prints the Decision JSON and launches nothing. Exit 0. |
| `mad run [--agent A] [--model M] [--dry-run] PROMPT [FILE...]` | Routes, appends a `transition` log entry, then `exec`s the CLI. `--dry-run` prints the argv (shell-quoted) and skips both the exec and the log append. |
| `mad log --kind K --agent A [--field k=v]... MESSAGE` | Appends one entry (`task: MESSAGE` plus fields). |
| `mad handoff` | (Phase 2) `exec agy --model gemini-4-argon-high -i "$(cat .opengsd_handoff.md)"`. Exit 1 if the file is missing. |
| `mad check` | (Phase 3) Updates telemetry and prints `ok` or `handoff`. Exit 0 for ok, 10 for handoff. |

Binary paths come from `MAD_CLAUDE_BIN` and `MAD_AGY_BIN` (defaults `claude`, `agy`). The repo root is the
nearest ancestor of the current directory that contains `.global_dev_log.md` or `.git`. Usage errors exit 2.

## 6. Skills (Phase 2)

All three live in `skills/<name>/SKILL.md` with the standard frontmatter (`name`, `description`). `scripts/install-skills.sh`
symlinks them into `~/.claude/skills/` and into the agy plugin dir. It changes the user's home, so it runs only on request.

- **context_orchestrator**: supersedes the existing `compacting-context-safely` / `handing-off-sessions` handoffs for
  this workflow. It doesn't edit those plugin skills. Steps: (1) work out the delta from `git diff --stat`, the files touched
  and decisions made since the last `handoff` log entry; (2) append a `handoff` entry; (3) write `.opengsd_handoff.md`
  (OKF) with exactly the sections `## Unresolved problem`, `## Next exact steps` (numbered), `## Context files to load`
  (paths in `.active_context/`), `## Verify with` (commands).
- **context_fetcher**: `mad fetch KEYWORD...` scores each `.active_context/*.md` by keyword overlap with its
  frontmatter `keywords` (2 points each) and title words (1 point each). It prints the paths with score > 0, highest first,
  stopping at `fetch_budget_bytes` (default 24000) of total file size. The skill tells the agent to read only those files.
- **route_task**: before a large task, run `mad check`. On `handoff`, run context_orchestrator, stop, and print
  `mad handoff` (or the raw `agy -i ...` line).

## 7. Telemetry and limits (Phase 3)

`.agent_telemetry.json` (version 1):

```json
{"version": 1, "updated": "2026-10-23T14:02:11Z",
 "claude": {"window_hours": 5, "window_message_budget": 45, "handoff_ratio": 0.8,
            "messages_in_window": 12, "oldest_in_window": "2026-10-23T09:10:00Z"},
 "agy":    {"max_concurrent": 2, "running": 0, "last_rate_limit": null}}
```

- **Claude usage is estimated [fix]:** no command reports Pro usage, so `messages_in_window` counts user-prompt
  entries with timestamps in the last `window_hours` across all `~/.claude/projects/*/*.jsonl`, because the limit is account-wide.
  Handoff fires when `messages_in_window >= ceil(budget × ratio)`. With the defaults that is 36, which reconciles the
  brief's "~35 messages" with "80% capacity".
- **agy:** `running` counts live `agy` processes. A run that fails with rate-limit text in stderr sets `last_rate_limit`.
  If `running >= max_concurrent`, or a rate limit happened within 15 minutes, `check` hands back to claude.
- **Enforcement:** a project-level Claude Code `UserPromptSubmit` hook (`.claude/settings.json`) runs `mad check`.
  On exit 10 it injects the context_orchestrator instruction.

## 8. Out of scope

API keys and HTTP APIs; SQLite/Redis; automatic switching of a live session's model; a daemon; a GUI;
measuring the exact subscription quota (no source exists).

## 9. Testing

- `route.classify` is table-tested: every rule row in 4.1 and 4.2 gets at least one case, plus tie, no-signal and override cases.
- Store tests run in `tmp_path` and prove idempotence and append-only behavior. Pre-existing bytes must stay byte-identical.
- CLI tests (bats) use stub binaries that echo their argv to a file. No real CLI is ever launched.
